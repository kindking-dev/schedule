# Schedule + AITU Interactive Campus Map

Полноценная интеграция интерактивной карты кампуса **Astana IT University (AITU)** в персональное веб-приложение **Schedule (Расписание занятий)**.

Интеграция выполнена на базе оригинального репозитория [AITUMAP](https://github.com/Yuujiso/aitumap).

---

## 🎯 Ключевые возможности

1. **Интерактивная аудитория в каждой карточке:**
   - Для очных занятий отображается номер аудитории, корпус и аккуратная кнопка **«На карте ↗»**.
   - При нажатии открывается навигационная панель с автоматическим переходом на нужный этаж, плавным центрированием и пульсирующей подсветкой аудитории.
   - Для онлайн-занятий отображается лаконичный бейдж **«Онлайн»** с иконкой монитора (кнопка карты скрыта, выдуманные аудитории не создаются).

2. **Оригинальная векторная геометрия AITUMAP:**
   - 100% настоящая геометрия кампуса C1 (блоки C1.1, C1.2, C1.3) для 1-го, 2-го и 3-го этажей.
   - Никаких сторонних растровых картинок или внешних картографических сервисов.
   - Поддержка навигации: масштабирование (колёсико мыши, pinch-to-zoom на тачскринах, кнопки `+`/`-`), свободное перемещение (pan/drag), центрирование по кнопке-мишени, сброс вида на весь корпус.

3. **Точная привязка аудиторий из расписания:**
   - **`C1.3.362`** (Разработка безопасного ПО) ➔ **3 этаж**, Блок C1.3, графический узел `C1.3.362P`.
   - **`C1.2.245L`** (История и философия науки, практика) ➔ **2 этаж**, Блок C1.2, графический узел `C1.2.245`.
   - **`Актовый зал`** (История и философия науки, лекция) ➔ **1 этаж**, Блок C1.1, графический узел `ASSEMBLYHALL`.
   - **`Онлайн`** (Расширенная защита компьютерных сетей) ➔ онлайн-формат без вызова карты.

4. **Apple Maps & Linear эстетика:**
   - Минималистичная плавающая панель с блюром (backdrop-filter) и мягкими тенями.
   - Полная синхронизация со светлой и тёмной темами расписания.
   - Адаптивность: на компьютере модальное окно оптимальной ширины 820px, на смартфонах — полноэкранная панель с учётом `safe-area-inset`.

5. **Автономность и производительность:**
   - Ленивая инициализация: карта загружается только при первом открытии.
   - Полная локальная работа без обязательного подключения к внешнему интернету.

## 🚀 Инструкция по запуску на Windows

### Способ 1: Быстрый запуск в 1 клик (Рекомендуется)
Дважды кликните по файлу **`start.bat`**.
Скрипт автоматически запустит локальный сервер и откроет расписание в браузере по адресу `http://localhost:3000`.

### Способ 2: Через Node.js в терминале
```powershell
# Находясь в папке schedule:
npm start
# или: node server.js
```
Откройте браузер по адресу: **`http://localhost:3000`**

### Способ 3: Через Python
```powershell
python -m http.server 8000
```
Откройте: **`http://localhost:8000`**

### Способ 4: Прямое открытие файла (file://)
Вы можете просто открыть файл **`index.html`** напрямую в любом современном браузере (Chrome, Edge, Firefox, Safari). Вся векторная графика и скрипты карты работают автономно.

## 🧭 Протокол взаимодействия (postMessage API)

Автономная версия карты в `integrations/aitumap/` поддерживает двусторонний обмен сообщениями:

### Входящие команды в карту:
- `{ type: "OPEN_ROOM", room: "C1.3.362" }` — открывает аудиторию, переключает этаж и центрирует.
- `{ type: "SET_FLOOR", floor: 2 }` — переключает активный этаж (1, 2 или 3).
- `{ type: "SET_THEME", theme: "dark" | "light" }` — устанавливает тему оформления.
- `{ type: "CENTER_ROOM" }` — центрирует вид на выбранной аудитории.
- `{ type: "RESET_VIEW" }` — сбрасывает масштаб до общего плана этажа.

### Исходящие события карты:
- `{ type: "MAP_READY" }` — карта успешно инициализирована.
- `{ type: "ROOM_FOUND", room: "...", floor: 3, elementId: "..." }` — аудитория найдена и подсвечена.
- `{ type: "ROOM_NOT_FOUND", room: "..." }` — аудитория не найдена.
- `{ type: "ROOM_CLICKED", room: "..." }` — пользователь кликнул по аудитории на карте.
- `{ type: "FLOOR_CHANGED", floor: 2 }` — изменён отображаемый этаж.
